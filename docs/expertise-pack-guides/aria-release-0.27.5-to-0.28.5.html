1. Main-Agent Non-Cached Callout & Sub-Agent Resolution

Separates main-window context pressure from isolated sub-agent runs, highlights non-cached tokens up front, resolves every sub-agent's persona and model, and removes the redundant isolated window column.

v0.28.3 · v0.28.4 · v0.28.5
1 Main-Agent Non-Cached Callout Dedicated banner directly below the hero showing billed non-cached input tokens (or estimated uncached window tokens when OTel is off), cached %, peak prompt, and turns isolated to sub-agents.
2 Resolved Agent & Model Names Sub-agents now resolve persona names from agentName, contract.json delegations, evaluation prompts, and OTel toolCallId spans, plus models from args.model or inherited session model.
3 Removed Dead Column Removed the noisy Non-cached / total (isolated window) column from the Sub-agents table and shows AIU only when measured spans exist.

2. Research Telemetry Cross-Workspace Safety, Chunk Scan & Prune

Prevents multi-window VS Code sessions from hijacking github.copilot.chat.otel.outfile, keeps Prune data always reachable whenever local or global OTel data exists, and strips multi-megabyte workspace embedding noise.

v0.28.4 · v0.28.5
1 No Silent Window Hijacking Opening another VS Code window no longer overwrites the global otel.outfile path, and enabling telemetry pre-creates .aria/runs/copilot-otel.jsonl.
2 Always-Visible Prune + Record Here Calculates prunable bytes across both the configured global path and local workspace copilot-otel.jsonl, surfaces a Needs you warning when pointing elsewhere, and adds 1-click Record here.
3 Embedding Bloat Protection otel_trim.py drops embeddings indexing spans on trim, while insights.js scans large OTel exports in 4 MB chunks so chat spans are never buried.

3. Bundled Example Expertise Pack, Workspace Packs & 1-Click Checklist

Ships the complete oracle-offering reference pack inside the VSIX, lists repo-committed plugins/<pack>/ packs in Mission Control, and adds a 1-click Pack checklist button opening Pack-Checklist.md.

v0.28.4 · v0.28.5
1 Built-In Oracle Offering Pack Bundled in runtime/examples/plugins/oracle-offering/ and shown directly on Skills & packs with a 1-click Install example pack button (and inside Install plugin).
2 Workspace Pack Discovery plugin.py list --workspace now surfaces packs committed under plugins/<pack>/ right alongside globally installed packs.
3 1-Click Pack Checklist Wiki Clicking Pack checklist opens docs/wiki/Pack-Checklist.md beside Mission Control with every manifest, prefix, safety, and validation rule.

4. White-Label Multi-Brand VSIX Engine & Configurable Icons

Drives product names, prefixes, state folders, Mission Control header logos, and VS Code Activity Bar icons from brand.json — allowing two separately branded VSIXs to build cleanly and run side-by-side in VS Code with full backward compatibility.

v0.28.0 · v0.28.5
1 Configurable Logo & Activity Bar SVG brand.json now accepts "logo" (Extensions view + Mission Control header via brand.css) and "activity_icon" (monochrome Activity Bar mask SVG).
2 Isolated Side-by-Side VSIX Builds python extension/build.py --brand nova.json --package dist/nova.vsix builds in a clean staging tree with isolated IDs (pwc.nova, nova.*, .nova/) without touching ARIA files.
3 Zero-Breakage Production Compatibility Default ARIA keeps pwc.frontier-hve, frontierHve.*, and ~/.frontier-hve; tools accept both <prefix>-plugin.json and legacy hve-plugin.json.

5. Copilot-Mode Live Tracking, Companion Mode & Batched In-Process Hooks

Brings first-class Live & Measured Telemetry to VS Code Copilot mode and Copilot CLI, adds Companion Mode when working in Claude Code / Cursor / Codex, trims the agent picker to the 4 main entry agents, and batches hooks in-process.

v0.27.6 → v0.28.2
1 Copilot Session-State Live & Telemetry Indexes ~/.copilot/session-state/<id>/events.jsonl + workspace.yaml so Copilot mode & CLI update Live steps and measured token/AIU metrics even with OTel off.
2 Companion Mode & Adapter Verifier Hooks record active external tools in .aria/runs/client.json (showing Working in Claude Code / Cursor + Copy start command), and check.py dry-runs hooks on install.
3 Batched Hooks & PreCompact Anchor PreToolUse / PostToolUse guards run inside one Python process, skills load 1-line descriptions first, and PreCompact re-hydrates ask context after compaction.
